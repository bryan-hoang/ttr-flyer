# ttr-flyer

A Python script that generates a flyer.

Specifically, for
[Tom Tech Repairs](https://www.facebook.com/TomtechRepairsKingston/).

## Install

Prerequisites:

- [`uv`](https://docs.astral.sh/uv/#installation)

```sh
git clone https://github.com/bryan-hoang/ttr-flyer.git
cd ttr-flyer
```

## Usage

```sh
uv run main.py
# View the generated koodo_church_promo_flyer.png
```
